# Тестирование в продакшене

[![hexlet-check](https://github.com/Anastasiia3110/qa-engineer-project-85/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Anastasiia3110/qa-engineer-project-85/actions)

## О проекте

**Codebattle** — веб-приложение с открытым исходным кодом, разработанное сообществом Hexlet.

Это многопользовательская игра для программистов, в которой два участника одновременно решают одну и ту же задачу на разных языках программирования. Побеждает игрок, который первым правильно выполнит задание.

Приложение позволяет играть с другими пользователями, друзьями или ботом, выбирать уровень сложности и язык программирования, а также отслеживать результаты игр и рейтинг участников.

**Тестируемое приложение:** https://codebattle.hexlet.io/

**Учебный проект Hexlet:** https://ru.hexlet.io/programs/qa-engineer

## Цель проекта

Изучение и тестирование веб-приложения Codebattle с целью проверки его функциональности, выявления дефектов и оценки качества пользовательского интерфейса.

В рамках проекта планируется:
- Изучение функциональных возможностей приложения.
- Проверка основных пользовательских сценариев.
- Тестирование регистрации и авторизации.
- Проверка создания и настройки игр.
- Тестирование игрового процесса и редактора кода.
- Проверка корректности отображения результатов.
- Выявление и документирование дефектов.

## Содержимое репозитория

- `.github/` — директория с настройками GitHub.
- `.github/workflows/hexlet-check.yml` — конфигурация автоматической проверки проекта Hexlet.
- `README.md` — описание тестируемого проекта и документация репозитория.

По мере выполнения проекта репозиторий будет дополняться материалами по тестированию.

## Стек

- Codebattle — тестируемое веб-приложение.
- GitHub — система хранения кода и управления репозиторием.
- GitHub Actions — автоматизация проверок репозитория.

## Установка

Для получения локальной копии репозитория выполните команды:

```bash
git clone https://github.com/Anastasiia3110/qa-engineer-project-85.git
cd qa-engineer-project-85
```

## Использование

Тестирование выполняется через веб-интерфейс приложения Codebattle: https://codebattle.hexlet.io/

В ходе работы исследуются пользовательские сценарии, проверяется функциональность приложения и документируются обнаруженные дефекты.
